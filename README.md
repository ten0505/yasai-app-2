# 新 家庭菜園管理アプリ

秋冬作（2026〜）向けの家庭菜園管理アプリ。前作 [yasai-app](https://github.com/ten0505/yasai-app) の後継です。

## 主な機能
- **日単位の一括入力**: 1画面で「日時・環境／実施作業（畑全体・作物ごと）／予定作業／収穫」をまとめて記録
- **天気の自動取得**: Open-Meteo API から千葉県印西市戸神の天気・風・気温を日付と時間帯で自動取得（過去日も可）
- **栽培タイムライン**: 作物×日付のマトリクス表示。実施・予定・収穫を色分け表示
- **野菜詳細**: 基本情報（発芽適温・生育適温・収穫までの日数など種袋情報入り）／スケジュール／収穫数
- **写真**: 長辺800px・JPEG65%に圧縮して保存（1作業あたり最大4枚）
- **クラウド同期**: Firebase Realtime Database（vegemane プロジェクト / yasai2 パス）。同期キーを設定した端末間で共有

## 使い方
1. GitHub Pages の URL をスマホ/PCで開く
2. 設定 → 同期キーを入力して「接続する」（全端末で同じキー）
3. 「記録入力」から日々の記録を入力

## 技術
- 単一 `index.html`（依存なし・ビルド不要）
- データ: localStorage + Firebase Realtime Database
- 天気: [Open-Meteo](https://open-meteo.com/)（無料・キー不要）
